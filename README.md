## Features

- Homepage with featured courses and academy information
- Course browsing and search
- Course details and a sample enrolment flow
- News and events
- Careers and job listings
- Illustrative staff content management panel
- Responsive layout and light/dark theme support

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

This is a front-end prototype. The staff panel and enrolment experience are illustrative and are not connected to a live database or payment service.

## Built with

- HTML
- CSS
- JavaScript

## Project status

Prototype for portfolio demonstration. The interface describes a possible future ASP.NET Core and SQL Server build; those backend services are not included in this repository.
